# Clips

New template, draft. Single-story short clips (30-60s, 9:16) in the same
terminal style as Daily Digest, but for one story at a time.

Structure: hook -> deep dive -> short branding end line. No 5-story
numbering, no 5-character montage — instead a single character+logo
pair at the end for that story.

See `template.yaml` for the full draft definition. Nothing uses this
template yet: no run, no cron, and no pipeline code change was made
when this folder was created. Confirm the draft parameters (especially
length and the end-pair) before wiring it into `run.py` / a schedule.

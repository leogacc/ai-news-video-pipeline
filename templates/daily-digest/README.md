# Daily Digest

The main template. This is the daily 9:16 video the 18:00 PT run ships:
5 stories, most-interesting-first, headline hooks first (no cold-open),
then the self-plug line, then deep dives.

See `template.yaml` for the full definition: format, structure, terminal
captions, number pills, hook heroes, the split self-plug montage, the
Pixar portrait rules, voice, and publish format.

Status: live. The run still executes from `pipeline/config.yaml` and
`pipeline/*.py`; this folder is the template definition, to be wired in
as a runtime input only when approved.
